# Footer

## Philosophy

The footer should feel like the closing section of the website, not an afterthought.

Think of it as a premium editorial layout.

Give the content generous breathing room and finish with an oversized faded brand wordmark spanning the full width of the page.

Avoid dense link lists or generic SaaS footers.

---

## Layout

Desktop

```txt
┌──────────────┬────────────────────────────────────┐
│              │                        Link Column │
│ Logo         │                        Link Column │
│ Tagline      │                        Link Column │
│              │                                    │
│ Newsletter   │                            Socials │
└──────────────┴────────────────────────────────────┘

┌───────────────────────────────────────────────────┐
│ Copyright                                     CTA │ 
└───────────────────────────────────────────────────┘

APP NAME
```

Mobile

```
Logo

Tagline

Newsletter

Links

Socials

Copyright

Large Brand Name
```

Stack naturally while preserving generous spacing.

---

## Main Grid

Desktop

```
30% | 70%
```

The left column introduces the brand. (left aligned)

The right column contains navigation and social links. (right aligned)

Do not center the footer.

---

## Left Column

Contains

- logo
- short brand statement
- optional newsletter signup

Allow generous vertical spacing.

Newsletter should sit near the bottom of the column.

---

## Navigation

Split links into multiple groups.

Example

```
Product

Company

Resources

Legal
```

Each group contains 3–6 links.

Headings should use muted uppercase labels.

---

## Socials

Place social icons in the lower-right corner.

Use outlined square buttons.

Keep icons monochrome.

Avoid colorful brand icons.

---

## Bottom Bar

Separate with generous spacing.

Contains

Left

- copyright
- attribution

Right

- single outline CTA

Example

```
Contact

Book Demo

Start Project
```

---

## Brand Wordmark

Finish the footer with an oversized brand name.

This element spans nearly the entire viewport width.

Use very bold typography.

```
8vw–14vw
```

depending on screen size.

The wordmark should not compete with the footer content.

Use a vertical text fade.

Example

```
white / 18%

↓

white / 10%

↓

transparent
```

Use a background-clip gradient or mask gradient so the text gradually disappears toward the bottom.

Do not use solid text.

Do not add outlines.

Do not blur the text.

The wordmark should feel integrated into the background.

---

## Styling

Background

Slightly darker than the page.

Border

Thin subtle borders only.

Padding

```
96–128px
```

Rounded corners optional.

Avoid glassmorphism.

Avoid heavy shadows.

---

Brand

Navigation Links

Bottom Bar

---

## Motion

Animate only

- social hover
- CTA hover
- newsletter input focus

The large brand wordmark remains static.

---

## Avoid

- Tiny centered footers
- Five identical link columns
- Large social logos
- Multiple CTA buttons
- Dense layouts
- Heavy shadows
- Glassmorphism
- Gradient borders
- Generic copyright rows

The footer should feel like the final editorial statement of the product.
